}
input: 从初始输入中提取 input 字段
memory: 异步加载存储在 Upstash Redis 中的对话历史
第2步：重组数据结构

{
  input: (previousOutput) => previousOutput.input,   // 透传用户输入
  history: (previousOutput) => previousOutput.memory.history, // 提取历史记录
}
将上一步的输出重新组织，匹配 prompt 模板需要的变量名
第3-4步

prompt,  // 用 {input} 和 {history} 渲染提示词模板
model,   // 发送给 GPT-3.5 获取回复
数据流向图

用户输入 ──┬──→ input ──┐
          │            ↓
          └──→ memory.loadMemoryVariables() ──→ history ─┘
                                                   ↓
                                           prompt模板渲染
                                                   ↓
                                              GPT-3.5回复
相比简单的 prompt.pipe(model)，这个自定义链增加了从 Redis 加载对话历史并注入到提示词的功能。
